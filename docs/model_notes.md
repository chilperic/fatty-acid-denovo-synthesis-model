# Model notes

The PhD thesis describes a semi-mechanistic model of fatty-acid de novo synthesis. The biological substrates and products emphasized in the repository are acetyl-CoA, malonyl-CoA, NADPH, CoA, and the fatty-acid products C14:0, C16:0, and C18:0.

The original project explored several model variants, including basic elongation, CoA inhibition, substrate competition, open-system assumptions, and enzyme-sinking/denaturation variants.
